# 🏦 Home Loan Approval Prediction

## 📌 Project Overview

This project predicts whether a home loan will be approved or not using machine learning algorithms based on applicant details.

## 📊 Dataset

The dataset includes applicant information such as:

* Applicant Income
* Coapplicant Income
* Loan Amount
* Loan Amount Term
* Credit History
* Gender
* Marital Status
* Education
* Self Employed

## 🤖 Machine Learning Models

* Logistic Regression
* Decision Tree
* Random Forest
* XGBoost

## 🤖 Final Model
XGBoost (Best Performing Model)

## 📈 Model Performance
Accuracy: 92%
AUC-ROC Score: 77%

## 🏆 Why XGBoost?

XGBoost performed better compared to other models like Logistic Regression, Decision Tree, and Random Forest by providing higher accuracy and better prediction capability.
